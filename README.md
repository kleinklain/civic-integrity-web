# Civic Integrity Movement

Website program edukasi antikorupsi (Pendidikan Kewarganegaraan TB4703, Universitas Telkom).
Situs statis: `index.html`, `video.mp4`, `poster.jpg`, folder `fonts/`. Deploy di Vercel tanpa build step.

Link pre-test dan post-test (Google Form) ada langsung di `index.html`. Formulir Lapor Aman mengirim ke Google Form tim lewat `FORM_URL` di skrip bawah.
Huruf Geist, Geist Mono, dan Geist Pixel (Vercel, SIL Open Font License, lihat `fonts/OFL.txt`).
